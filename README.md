# AURA // NEXUS — Next-Gen E-Commerce Storefront

An ultra-modern, high-performance e-commerce website engineered for modern tech, acoustics, and smart wearables. Built with clean semantic **HTML5**, **Vanilla CSS (Glassmorphism & Cyberpunk Neon Aesthetics)**, and modern **Vanilla JavaScript**.

---

## ⚡ Key Features

- **Sleek Cyber Glassmorphism**: Tailored dark theme with backdrop blur filters, glowing gradients, and smooth micro-interactions.
- **Light / Dark Mode Toggle**: Instant theme switching persisted in `localStorage` with system default fallback.
- **Live Search & Instant Filtering**: Debounced instant search across titles, specs, categories, and descriptions with one-click clear (`✕`).
- **Dynamic Category Navigation**: Quick-filter by *Audio & Acoustics*, *Wearables & Rings*, *Computing & Peripherals*, *Smart AR Optics*, and *Autonomous Drones*.
- **Quick Spec View Modal**: High-definition product inspection modal with hardware architecture tags, live stock status, and direct add-to-cart.
- **Slide-Out Cart Drawer**:
  - Live item count badge and subtotal preview in the header.
  - Interactive stepper (`+` / `−`) and instant removal.
  - Dynamic **Free Express Shipping Progress Bar** ($150 unlock threshold).
  - Promo code discounts system (`CYBER20` for 20% off, `AURA15` for 15% off, `WELCOME10` for 10% off).
- **Wishlist Engine**: Heart toggle with persistent favorite storage in `localStorage` and a dedicated favorites drawer.
- **Quantum-Encrypted Checkout Simulation**:
  - Multi-method selector (Credit Card, Apple Pay, Bitcoin/Crypto).
  - Field validation with visual feedback.
  - Simulated payment authorization with loading spinner.
  - **Celebration Screen**: Custom animated order confirmation with generated Order Number (e.g., `#AUR-98421`), delivery estimates, and interactive confetti particle fireworks!
- **Multi-Currency Support**: Instant conversion between **USD ($)**, **EUR (€)**, and **GBP (£)**.
- **Toast Notifications**: Non-intrusive floating status alerts for cart updates, coupon redemptions, and wishlists.

## 🚀 How to Run Locally

### Option 1: Live Local Server (Currently Running on Port 8000)
Visit in any browser:
```text
http://localhost:8000
```

To restart the server at any time:
```powershell
python -m http.server 8000
```

### Option 2: Direct File Open
You can also directly double-click or open [index.html](file:///c:/Users/nanda/OneDrive/Desktop/firdtproject/index.html) in any browser (Chrome, Edge, Firefox, Safari).
